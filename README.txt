FOCUS LOCK — CHROME EXTENSION
Version 1.1.0

WHAT IT DOES
- Blocks websites you add while a focus session is active.
- Includes 25, 50, and 90 minute focus sessions.
- Includes a default list: YouTube, Reddit, Instagram, TikTok.
- Blocks the selected domain and its subdomains.
- Stores your settings locally in Chrome.
- Includes a redesigned, responsive-feeling popup interface with a live timer and progress indicator.

INSTALL ON CHROME (MAC)
1. Unzip focus-lock-chrome-extension.zip.
2. Open Chrome and go to: chrome://extensions
3. If your administrator allows it, turn on Developer mode and use Load unpacked.
4. Select the unzipped "focus-lock" folder containing manifest.json.
5. Pin Focus Lock from Chrome's Extensions menu.

PACK THE EXTENSION
1. Open chrome://extensions.
2. Select Pack extension.
3. Choose the extracted "focus-lock" folder as the extension root directory.
4. Leave the private key blank the first time and select Pack Extension.
5. Chrome creates a .crx package and a .pem key. Keep the key private and backed up.

USE
- Click the Focus Lock extension icon.
- Add domains such as twitch.tv or discord.com.
- Choose 25, 50, or 90 minutes.
- Click Start focus session.
- Click End session early to stop early.

IMPORTANT LIMITATIONS
- This is a personal productivity aid, not tamper-proof parental-control software.
- Because it runs as a Chrome extension, it only blocks sites in this Chrome profile.
- A user with access to Chrome's extension settings can disable or remove it.
- It does not block other browsers or apps.
- It does not collect or transmit browsing history or personal data.
- Packing an extension does not bypass administrator or school-managed installation restrictions. Follow your device administrator's rules.
